What changed
Vectorize an image to see optimization statistics.
01

Cluster color

Pixels are grouped in perceptual Lab color space, producing a compact palette before any tracing begins.

02

One object per region

Each spatially connected component is separated into its own stable SVG object instead of merging unrelated areas that share a color.

03

Reduce points

Collinear cleanup plus Ramer–Douglas–Peucker simplification removes unnecessary polygon vertices.

04

Edit & recover geometry

Drag polygon vertices directly in the preview. Round contours can still become native <circle> or <ellipse> primitives.
